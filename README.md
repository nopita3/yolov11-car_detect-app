# yolov11-car_detect-app

YOLOv11-based vehicle intelligence project developed in my **AI for Business** workshop class.

## Motivation
I built this project because I’m passionate about applying AI to real business and social problems.  
Transportation data is valuable for improving operations, safety, and decision-making.  
This project combines technical AI skills with practical business use cases by detecting both **cars** and **license plates (ป้ายทะเบียน)** from road-scene data.

## Project Overview
This project implements an object detection pipeline using YOLOv11 to identify and localize:
- **Cars**
- **License plates (ป้ายทะเบียน)**

from images and video frames.

## Business Relevance
This project demonstrates how computer vision can support:
- Traffic flow monitoring and planning
- Parking management and access control
- Urban mobility analytics
- Operational insights for transportation-related businesses

## Objectives
- Build a working YOLOv11 detection workflow
- Detect cars and license plates with bounding boxes and confidence scores
- Create a reusable notebook pipeline for AI experimentation
- Connect AI outputs to business-oriented applications

## Tech Stack
- Python  
- Jupyter Notebook  
- YOLOv11 (Object Detection)

## Workflow
1. Prepare image/video input data  
2. Run YOLOv11 inference  
3. Extract detections (class, confidence, bounding box)  
4. Visualize and analyze results  

## Output
- Car detections with confidence scores  
- License plate detections with confidence scores  
- Visualized prediction results for analysis and improvement  

## Learning Outcomes
Through this workshop project, I strengthened my skills in:
- Applied computer vision engineering
- Model testing and result interpretation
- Translating AI prototypes into business value
